# Retail Performance Dashboard (Power BI)

## Overview
This project analyzes retail sales data to understand performance across sales, customers, products and operations.

The goal is to identify what drives revenue, where profit is lost and how operations can be improved.

---

## Tools Used
- Power BI  



---

## Dataset
The dataset contains ~5,000 orders, including:
- Sales and profit  
- Customer information  
- Product categories  
- Shipping details

## Key Insights
- Sales peak in **December (43,369)** and drop in January  
- A small group of customers drives a large share of revenue  
- **High discounts reduce profit without increasing sales**  
- **Copiers** are the most profitable subcategory  
- **Accessories** underperform despite generating sales  
- **Standard Class shipping** is the most profitable  
- **Same Day delivery** is the least efficient  

---

## Data Cleaning and Preparation 
- Cleaned and structured the dataset  
- Built a **4-page interactive dashboard** in Power BI  
- Created key metrics like **AOV ($458.6)** and **Profit Margin (12.5%)**  
- Analyzed sales trends, customer behavior, and delivery performance
